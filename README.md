# WebStoreConsoleApp

A simple console application for managing a web store, built with .NET and Entity Framework Core. It uses a SQLite database for storage.

## Features

*   Add and view customers
*   Add and view products
*   Place new orders for customers
*   View customer order history

## Tech Stack

*   C# / .NET
*   Entity Framework Core
*   SQLite

## Getting Started

### Prerequisites

*   [.NET SDK](https://dotnet.microsoft.com/download)

### How to Run

1.  Clone this repository.
2.  Open a terminal in the project's root directory.
3.  Run the app:
    ```bash
    dotnet run
    ```
4.  The first time you run the app, EF Core will create a `store.db` file in the output directory.

## Usage

Run the application and use the menu to navigate. You can add customers, place orders, and view data by following the prompts.
